## 🚀 Overview

Flourish Studio is a clean, single-file storefront built with **HTML5, CSS3, and Vanilla JavaScript**. It’s engineered for creators who need a polished editorial design that converts mobile traffic into sales without the bloat of a full e-commerce backend.

> "Designed to be easy to customize, fast to deploy, and strong enough to share as a professional portfolio piece."

---

## ✨ Why It Stands Out

- **🧠 AI-Powered SEO**: Generate compelling product descriptions and SEO-optimized titles in seconds, boosting discoverability and conversions.

- **💎 Polished Editorial Design**: Move beyond generic store templates with a layout that feels like a premium brand.
- **📱 Mobile-First Excellence**: Fully responsive design that feels intentional on both mobile and desktop.
- **🔗 Direct Checkout Hooks**: Native support for Selar, Gumroad, Payhip, and more.
- **⚡ Zero Dependencies**: No build steps, no frameworks, just pure speed.
- **🔍 SEO Optimized**: Pre-configured metadata for search engines and social media sharing.

## 🛠️ Quick Start (Get Live in 5 Mins)

1. **Clone the repo**
   ```bash
   git clone https://github.com/Informant254/flourish-studio.git
   ```
2. **Update Content**
   Open `index.html` and replace placeholder product names, prices, and images.
3. **Set Checkout**
   Update the `CHECKOUT_URL` constant with your Selar or Gumroad link.
4. **Deploy**
   Drag and drop the folder into [Netlify](https://www.netlify.com/) or [Vercel](https://vercel.com/).

Easily tweak the design to match your brand:

- **Typography**: Change fonts in the CSS header.
- **Socials**: Update footer links to your Twitter, Instagram, or LinkedIn.
